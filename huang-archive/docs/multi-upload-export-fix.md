# 多选上传 + 完整备份导出

## 1) 多选照片只见一张

**根因**：`media_files` 已可一次写入多张（API/端测证实 3 张入库）；网格卡片原先只渲染首张缩略图，看起来像「只成功一张」。

**修复**：
- 上传：多文件唯一文件名（`_p1/_p2…`），一条档案保留全部文件
- 卡片：`N/M 张` 角标、左右翻页、底部缩略图条；点击可看大图
- 弹窗提示：已选择 N 个文件，将保存为一条档案

**端测**：UI 上传 3 张 → `media_files.length=3`，角标 `1/3`→下一张 `2/3`；测后已删。

## 2) 备份导出

**根因**：原「备份导出」只下 JSON 元数据，不含文件。

**修复**：一键下载 ZIP（`fflate`）：`manifest.json` + 每条档案 meta + `media/`/`cover/`/`playback/` + 留言语音。

**端测**：样例 ZIP 含多图档案的全部 media 文件；已部署。

截图见 store `media/multi-*.png`、`e2e-full-backup-sample.zip`。
