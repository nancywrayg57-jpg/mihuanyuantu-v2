# 蜜獾原图 v2 本地仓库整理

## 1. 授权与范围

用户要求在本地整理项目仓库，完善 `.gitignore`，暂不推送到指定远程。保留当前目录结构、原始资料、底座许可证和源码，不改业务逻辑、需求、架构或生产配置。

## 2. 仓库边界

- 根目录为 `D:\workspace\蜜獾原图v2`。整理前根目录及 `aojuai-main` 均无 `.git`。
- 根仓库统一管理 `aojuai-main/`、`docs/` 和 `输入材料/`；底座作为普通目录，不建立子模块，也不伪造其上游版本或历史。
- 根 `.gitignore` 补齐多技术栈依赖、生成文件、实际环境配置、私钥及本地运行数据；保留底座各层现有忽略文件。锁文件、迁移、环境模板及输入资料压缩包纳入版本控制。
- 与仓库同级的 `生产物料/` 含凭据；禁止入库。记录只保存文件排除结论，不保存任何密钥值。
- `.gitattributes` 约束代码文本行尾；`docs/` 和 `输入材料/` 禁止 Git 自动换行转换，保持原始输入；二进制保持原字节。
- 本地 `main` 与 `origin` 配置只写本地 Git 元数据；推送由用户另行授权。

## 3. 约定摘要

- 私有目录、实际环境值、依赖、缓存和产物排除；模板、锁文件、迁移、OpenAPI、源码和输入资料保留。
- 仓库同级 `生产物料/` 与实际环境值不可纳入 Git；不把本地整理视为远程发布或应用运行验收。
