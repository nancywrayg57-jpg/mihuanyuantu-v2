# 设备预设原型导入裁决

## 决定

- 平台管理员独立“设备预设”菜单的原型目录以 `输入材料/旧版可复用模块/02_设备参数/线上预设_脱敏原始.json` 为唯一导入源；GPS 只在新建/编辑设备预设弹窗的“EXIF / GPS”选项卡配置，系统设置页面不承载设备或 GPS。
- 导入 405 条唯一记录，不把按旧分类、建议设备形态和完整候选文件重复叠加为更多记录。
- 每条记录保留源文件的 58 个参数字段，并附带来源 ID、模板引用、建议设备形态、分类依据、复核桶、复核标记、旧可见性和采集日期。
- 405 条记录的源字段继续保持 `PRIVATE`、`NOT_ACTIVATED`；233 条显示为“结构候选”，172 条显示为“待复核”。记录默认未启用，但平台管理员可以从原型直接启用或停用；启用只改变平台可用状态，不覆盖源证据，也不替代规格核验。
- 原有 3 条公共演示预设继续保留，用于批量原图表单的固定演示；它们与旧版导入记录分开标识。

## 原型实现

- 数据夹具：`prototype/device-presets.js`。
- 页面入口：`prototype/index.html`。
- 设备预设目录提供名称/相机/镜头/来源搜索、设备类别筛选、复核状态筛选、分页和逐条完整参数详情。
- 数据夹具通过外部脚本加载，以便直接双击 `prototype/index.html` 演示；不调用真实 API、数据库或旧版站点。
- 浏览器 `localStorage` 载入旧状态时按 ID 合并新目录，保留管理员已有的演示配置和状态变更。
- GPS 配置不再作为设备预设菜单的独立列表页；平台管理员和商家按各自权限在新建/编辑设备预设弹窗中配置 GPS，商家保存不修改平台公共预设状态。
- 新建/编辑设备预设共用弹窗表单；EXIF / GPS 区域随 GPS 模式联动：`none` 隐藏坐标与随机场景，`fixed` 显示纬度/经度/海拔，`random_by_scene` 显示随机场景。字段 placeholder 使用原版示例值，选项卡名称为“AI提示词”，不保留版权字段。
- 工作台“新建批量原图”进入独立“批量原图”页面（`direct` 路由）；工作台右上角不再提供“开始一批原图”。

## 验证边界

- 已核对 405 个唯一 ID、58 个源参数字段、233/172 复核分布，以及全部 `PRIVATE`/`NOT_ACTIVATED` 标记。
- 已进行 HTML/JavaScript 语法检查、HTTP 页面走查、管理员权限页面走查、详情字段走查、筛选分页、刷新恢复、窄屏尺寸和控制台错误检查。
- 这些证据只证明离线 HTML mock 的数据展示和交互，不证明厂商规格、EXIF 回读、图像效果、后端迁移、公共模板发布或生产运行时已完成。
- 2026-10-27 增量回归确认：工作台入口 URL 为 `#direct` 且页面标题为“批量原图”；新建设备预设弹窗的 EXIF / GPS 在 `none`、`fixed`、`random_by_scene` 三种模式下分别呈现对应字段。

## 2026-10-27 增量裁决（覆盖 GPS 独立页）

- 删除“设备预设”菜单内独立的“GPS 配置 / GPS 预设”页面；GPS 配置只保留在新建/编辑设备预设弹窗的“EXIF / GPS”选项卡中，并继续随 GPS 模式联动呈现字段。
- “批量原图”的本地上传和外部地址两个来源统一采用原版批量页的“EXIF 参数预设”三级联动：设备类型 → 设备品牌 → 设备型号；品牌和型号选项随上级选择变化，参数预览实时展示原版 EXIF 字段；提交任务从设备预设快照继承 GPS，不再提供独立“GPS 记录”选择。
- 本增量仍是离线 HTML mock，未改变 405 条导入目录、平台管理员启停权限或真实后端边界。
