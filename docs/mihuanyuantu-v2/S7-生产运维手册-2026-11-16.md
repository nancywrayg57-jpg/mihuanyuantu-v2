## 5. 出口代理（Gemini 地区限制，方案 A）

生产出口（阿里云香港）被 Gemini 拒绝：`User location is not supported for the API use.`

现状：已在应用机部署 `gemini-egress-proxy.service`（Xray，读取管理员提供的 vmess 订阅节点），本地 `127.0.0.1:7890`，出口为节点所在允许地区；`09_proxy.sh` 已把该本地代理注入四个单元。

```sh
systemctl status gemini-egress-proxy --no-pager      # 出口客户端
sh /root/蜜獾原图-v2/shared/09_proxy.sh apply http://127.0.0.1:7890
sh /root/蜜獾原图-v2/shared/09_proxy.sh revert
sh /root/蜜獾原图-v2/shared/11_xray_setup.sh          # 重新拉取订阅并生成 Xray 配置
```

- 订阅 token 只存于 `shared/`（0600），**不入库、不打印**。
- 只影响 `api/process/notify/cleanup` 四个单元；`NO_PROXY` 保留 dashscope / aoju / deepseek / 内网直连。
- apply/revert 已在生产空跑验证（注入 6 个变量、revert 归零、单元不中断）。
- **该节点是第三方订阅，名称含到期日 2026-12-06**：到期前必须换成自有 SG/JP 代理，否则检测中断。

## 6. 密钥与轮换

- 位置：`shared/backend.env`、`shared/duty-secrets.json`（`chmod 600`，属主 root）。
- 轮换上游 Key：改 `duty-secrets.json` 后 `systemctl restart realphotos-api realphotos-process`；或在「系统管理 → 模型 API」由管理员改合同（写库，不落盘）。
- 轮换数据库口令：`ALTER ROLE realphotos_app PASSWORD ...` → 同步 `backend.env` → 重启 api/process/notify/cleanup。
- **禁止**把密钥写入仓库、PR、日志；日志只写 `present=true` / HTTP 码。

## 7. 常见故障

| 现象 | 先看 | 处置 |
| --- | --- | --- |
| 公网 502 | `systemctl status realphotos-web` | 前端未起或构建缺失，`pnpm build` 后重启 |
| 公网 403（`/health`、`/api/v1/*`） | Nginx 是否注入 `x-aoju-proxy-key` | 用 `shared/nginx-exif-demo.app.conf` 覆盖并 reload |
| 登录页能开但接口 401/403 | API `AOJ_PROXY_SHARED_SECRET` 与 Nginx 是否一致 | 改 env 后重启 api |
| 任务失败 `EXIF_WRITE_FAILED` | `which exiftool` | `apt-get install -y libimage-exiftool-perl` |
| 任务失败 `GEMINI_TECHNICAL` | 出口是否被地区限制 | 见 §5；用 `curl -x` 验证代理可达 |
| 任务卡 pending | `systemctl status realphotos-process` | worker 未起或 DB 不可达 |
| 迁移报 `No module named 'psycopg'` | `pip show sqlalchemy` | 必须 `>=2.0.36,<2.1`（2.1 会改用 psycopg3） |

## 8. 备份与恢复（手工规程）

```sh
# 每日备份（建议 cron）
mkdir -p /root/backup
PGPASSWORD=$(cat /root/蜜獾原图-v2/shared/db_password.txt) \
  pg_dump -h 127.0.0.1 -U realphotos_app -d realphotos_prod -Fc \
  > /root/backup/realphotos_prod-$(date +%F).dump

# 校验与恢复演练（在隔离库做，勿覆盖生产）
```

## 9. 端测口径（复跑用）

1. 确认应用已切流（§4）且四角色可登录。
2. 商家提交一张真实图 → 轮询任务到 `DELIVERED`；检测报告 `detector` 必须是 `gemini-*`，不是 `fixture`。
3. 生图抽样：提交 1 张 `text_to_image`，确认入库且不自动进入处理链。
4. 预审抽样：处理任务的前置预审返回 200 即算供应商可达；业务拒绝按 PRD 记，不算基础设施失败。
5. 验证码：生产为图形验证码；运维端测可在库内把某个 challenge 的 `code_hash` 预置为已知验证码（`sha256(码)`），登录接口逻辑不变。
