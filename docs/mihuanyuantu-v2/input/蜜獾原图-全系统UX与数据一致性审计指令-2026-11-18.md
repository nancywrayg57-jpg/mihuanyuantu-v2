## 0. 执行铁律

1. **先审计、后修复**：U1–U2 只读，不改代码、不改生产数据、不重启服务；审计报告经管理员确认后再进入 U3–U7。

3. **Git 纪律**：从最新 `main` 拉 `cursor/<功能简述>-9973`；禁止直推 `main`；只走 PR + squash merge；PR 必须 `CI gate` 全绿；合并由 Owner 执行，Collaborator 不自评自合。
4. **生产纪律**：部署必须管理员明确确认；部署前记录回滚点；不新增/修改数据库迁移除非单独批准；不触碰 `shared/backend.env` 等生产密钥。

7. **不暴露密钥与内部路径**：截图、日志、报告不出现 Key、口令、私钥、`shared/` 路径内容；资源只经网关展示。
8. **不改产品边界**：不新增 PRD 禁止的能力（客户自建上游 Key、OSS 必选、ZIP 交付、独立 GPS 页、生图成功自动进处理等）。
9. **术语与文案**：代码/接口/配置标识保持英文；面向用户的文案用中文；禁止把内部权限串、状态码、开发备注直接展示在 UI。

## 2. 审计维度

### 2.1 冗余标注与开发态残余

排查所有页面标题、卡片头、表头、按钮旁、抽屉标题、空态文案：

- 裸权限串（如 `需要以下权限之一：realphotos:admin:read`）
- 内部状态码/枚举（`DELIVERED`、`copy_no_reserve`、`detection_not_passed` 等）直接展示给用户
- 开发说明/PRD 备注/测试提示（“仅测试”“Mock”“fixture”“内置角色不可删除”等）
- 重复信息：顶部栏姓名/角色/ID 重复、页面标题与副标题重复、按钮与说明重复
- 术语不一致：同一对象在不同页面叫法不同（任务/编号/单号、预设/机型、积分/点数）
- 无意义副标题：把接口路径、权限规则、实现机制当页面说明

**例外**：fixture/替身检测路径的审计标识是产品诚实性要求，不得为了“干净”而隐藏；只允许放在管理员/技术视图，不放到商家主流程。

### 2.2 测试污染数据

- 数据库/种子中是否残留 E2E 改坏的姓名、角色、状态、余额
- 是否为演示写死了客户数据/假任务
- 测试账号是否被误当作真实客户展示
- 生产是否存在调试开关、临时文案、临时域名、临时供应商

**方法**：对照 `bootstrap.py` 的种子账号、`progress.yaml` 的证据、生产库抽样；不能只看 UI。

### 2.3 跨视图单一事实源（SSOT）

同一实体在多个视图中的字段必须一致、可双向定位：

| 实体 | 视图 | 必须一致的字段 |
| --- | --- | --- |
| 处理任务 | 工作台最近历史 / 任务详情列表 / 任务详情弹窗 / 积分流水 / 消息中心 | 租户内任务号、类型前缀、状态、预设名、失败原因、时间、缩略图 |
| 生图任务 | 工作台 / 生图页最近生成 / 任务详情生图页签 / 图片资源 / 积分流水 | 租户内生图号、尺寸、数量、资产、扣费 |
| 图片资源 | 图片资源列表 / 批量原图待处理 / 任务详情 / 消息图片名 | 文件名、资源 id、锁定状态、来源、缩略图 |
| 积分 | 工作台卡片 / 积分页余额 / 流水 / 任务详情积分处置 | 可用、冻结、变动后余额、关联任务 |
| 设备预设 | 设备预设（管理员/只读） / 批量原图摘要 / 任务详情预设快照 / 检测报告 | 品牌、型号、ISO、快门、光圈、焦距、GPS |
| 租户/账号 | 用户管理列表 / 租户详情 / 工作台 / 登录会话 | 租户名、状态、账号数、创建时间、最近活跃、余额 |
| 工单 | 工单列表 / 工单详情 / 商家申诉记录 / 消息 | 编号、类型、状态、创建时间、等待时长、关联任务/图片 |
| 业务 API | 凭证列表 / 创建/轮换结果 / OpenAPI | 名称、前缀、状态、创建时间、最近调用、scope |

重点排查“一处有、另一处为空/—/待完善”的割裂，以及“列表与详情口径不同”（如全局 id 与租户内编号混用）。

### 2.4 主流程可完成性

- 商家首图：上传/导入 → 选预设 → 扣费确认 → 提交 → 检测 → 下载
- 失败处理：检测未通过 → 重新处理 / 按参数复制 / 申诉 → 解锁
- 积分对账：冻结 → 消费/释放 → 流水 → 导出
- 生图：提交 → 最近生成 → 去处理
- 租户管理：创建租户 → 注册自动 provisioning → 账号 → 删除限制
- 业务 API：创建 → 列表 → 轮换/吊销 → 最小调用
- 消息：任务号/图片名 → 类型筛选 → 同批合并 → 直达任务

### 2.5 交互与可访问性

- 弹窗：Esc、初始焦点、Tab 焦点陷阱、关闭恢复焦点、`aria-modal`、表单类禁止遮罩误关
- 键盘可达：按钮/表单/下拉/分页
- 加载：骨架屏、按钮 loading、重复点击禁用、上传/下载进度
- 错误：可读的中文错误、可重试、不暴露堆栈/内部码
- 移动端：表格横向滚动 + 提示、操作按钮不裁切、卡片密度
- 空态：引导式文案 + 主行动按钮，而不是“暂无数据”

### 2.6 视觉与文案一致性

- 同层级页面标题、间距、表格密度一致
- 状态色语义一致（成功/失败/处理中/锁定）
- 时间格式统一（`YYYY-MM-DD HH:mm`）
- 金额/积分/字节单位统一
- 按钮主次层级一致，危险操作二次确认
- 不出现英文表头、溢出长文本、竖排单字（如“启/用”）
