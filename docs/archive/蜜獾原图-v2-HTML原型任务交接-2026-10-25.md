## 6. 必须模拟的核心业务流程

### 6.1 上传图片/外部导入独立处理流程

`选择上传或外部导入 → 基础校验 → 预审 → 冻结预计积分 → 五层技术处理 → Gemini Vision 最终检测模拟 → 结果交付 → 生成历史 → 链级计费`。

该流程不调用文生图或图生图模型，用户提交的图片直接作为五层处理输入；单次支持 1—10 张，保留每张图片的处理状态、检测报告、结果和积分状态。外部导入只允许使用确定的 mock/demo 地址或测试替身，不发起真实供应商请求。

### 6.2 文生图/图生图生成与后续 EXIF 选择流程

`选择大类 → 填写生成参数 → 生成请求 → 生图中 → 生成结果 → 客户选择“继续 EXIF 处理（整批）/ 暂不处理”`。

AI 生图阶段只创建生成结果，不执行或展示基础输入校验、预审、五层处理、Gemini 最终检测和结果交付，也不在此页选择设备预设或 GPS。生成结果可预览和下载 mock 地址；选择继续后，本批次全部图片一次性进入“批量原图”，再由设备预设驱动 EXIF/GPS 处理并进入独立图片处理链。选择暂不处理时结果保留在生成历史。原型可使用占位图片和可控演示数据，不得声称模型真实返回。

### 6.3 自动重做流程

- 默认关闭；开启后默认追加 1 次，可设 1—5 次；阈值默认 70 分，可设 0—100。
- 触发条件：上一轮有有效分数且 `total_score < threshold`，等于阈值不触发；技术异常、缺分、无有效结果不触发。
- 自动轮次以上一轮有效结果为输入，只模拟五层处理和最终检测，不重新模拟文生图/图生图，也不重新导入原图，不覆盖旧结果。
- 阈值高于 75 时，检测基线已通过但低于用户阈值的结果仍可继续重做。
- 任一轮达到检测通过标准且有有效结果，整条链只消费 10 积分；全部轮次未通过则免费；重复点击/重复回调不得重复扣费。
- 详情页展示 `round_no`、每轮状态、分数、报告、触发原因、输入/输出和链级计费状态。

推荐演示场景按钮：`生成成功`、`低分触发重做`、`阈值相等不重做`、`首轮通过后续失败`、`全部轮次失败`、`技术异常不重做`、`重复回调`。

### 6.4 统一生成历史流程

历史以任务链为主记录，不以单次前端卡片为唯一状态来源。列表默认展示文生图和图生图，并可切换查看上传、外部导入；列表和详情至少展示：来源、提交时间、当前状态、轮次数、最终可下载结果、检测报告摘要、是否消费、积分流水引用。独立检测结果入口不存在。

### 6.5 系统设置与账号隔离流程

系统设置按角色和作用域展示，原型只模拟权限判断和服务端保存反馈：

| 角色 | 可见标签 | 作用域与行为 |
| --- | --- | --- |
| 商家 | 自动重做、批量原图 | 仅当前租户任务与设置；可使用设备预设三级 EXIF 选择，GPS 随设备预设快照使用 |
| 技术客服 | 自动重做 | 仅授权工单范围；配置管理入口不开放，解冻仍在客服 / 管理后台按既有权限执行 |
| 平台管理员 | 自动重做、模型 API、用户与权限、设备预设 | 全平台配置与审计；可新增、编辑、启停设备预设，并在设备预设弹窗配置 GPS |

平台管理员设置页必须模拟以下内容：

1. **模型 API**：登记提供商、模型版本、用途、优先级和状态；提交 API Key 后只保存掩码，不写入或展示真实凭据。
2. **用户与权限**：展示账号、`tenantId`、角色、状态和权限范围；新增账号、角色变更、启停均写入权限审计。
3. **设备预设**：参考旧版参数管理布局维护设备类别、品牌、型号、相机、镜头、ISO、快门、光圈、EV、GPS 策略和预设版本；公共预设由平台管理员维护，批量原图按设备类型 → 品牌 → 型号选择并保存版本快照。
4. **GPS 配置**：只在新建/编辑设备预设的“EXIF / GPS”选项卡中管理 GPS 模式、固定坐标、随机场景和海拔；批量原图不再提供独立 GPS 记录选择。

平台级配置的列表、表单和操作均为 mock；不调用真实模型、地理编码或账号服务。旧版本布局仅用于交互认知参考，不直接迁移旧版用户归属或凭据。

## 7. 原型状态和演示数据建议

使用前端状态机模拟以下状态：

- `DRAFT`、`SUBMITTED`、`PRE_REVIEW`、`GENERATING`、`GENERATED`、`FULL_PROCESSING`、`DETECTION`

至少准备 8 组演示记录：

1. 文生图首轮通过，消费 10 积分。
2. 图生图低于 70 分，自动重做一次后通过，仍只消费 10 积分。
3. 图生图阈值设为 90，首轮 80 分已过 75 基线但继续自动重做。
4. 文生图所有轮次均未通过，有效结果可预览/下载但免费。
5. 技术异常，进入手动重试/客服路径，不自动重做。
6. 重复点击或重复回调，界面提示幂等且不重复扣费。
7. 直接上传本地图片，完成五层技术处理和 Gemini 检测，不经过文生图/图生图。
8. 使用外部导入 mock 地址，完成与上传相同的处理链路，并将来源记录为“外部导入”。

所有演示数据必须标记为 mock/demo，不调用真实供应商。
