# 蜜獾原图 v2 第一版本待决策清单

> 本清单与第一版本 PRD 配套保存，保留逐项问题、管理员裁决及后续设计和验证事项。当前 37 项 ND 的业务决策或执行规则均已确认，状态为 RESOLVED；尚未完成的具体设计、外部证据和验收单独标记为 PENDING，不能将决策完成等同于功能实现或上线验证通过。历史临时边界和裁决记录用于追溯，当前执行口径以各项最新裁决为准。

## 使用规则

- 每项都有稳定 ID `ND-NNN`，后续 PRD、架构、UX、任务和验收材料必须引用该 ID。
- `阻塞等级`：`P0` 表示阻塞真实上线；`P1` 表示阻塞相关能力验收；`P2` 表示后续版本或运营优化。
- `临时边界` 保留问题提出时的边界；已裁决事项以管理员最新回复及“管理员回复登记”为准，不再把旧临时边界当作当前开放问题。
- 当前问题列中括号内容为管理员回复；“管理员回复登记”是当前状态索引，37 项现均为 `RESOLVED`。裁决记录保留历史状态，不能用历史的 `RESOLVED_WITH_GATE`、`BOUNDARY`、`PARTIAL_OPEN`、`CONFLICT_OPEN` 或 `SCOPE_EXCLUDED_RISK` 覆盖当前状态。
- `RESOLVED` 表示该项业务决策或执行规则已确认，不代表功能已实现或验收通过；已确认的上线验证要求仍须保留，待补齐的证据单独标记为 `PENDING`。
- 当前执行口径以 **PRD document_version 2.7** 为准，覆盖本清单中仍写着更早版本的过时句。现行规则：图片先入「图片资源」，再选图提交「批量原图」；生图不自动五层/检测。计费为每张成功图片 10 积分——生图成功入库与图片处理通过检测分别计费，自动轮次不叠加；**生图不预冻、处理提交前冻结**；提示词优化成功 1 积分/次、失败不计费；ND-019 最终检测失败不收处理费。禁止 ZIP；GPS 只随设备预设快照（含 `random_by_scene`）。任务详情分处理/生图双标签，按账号隔离。预审默认阿里千问、生图默认 ChatGPT Image 2，均可配置更换。资金用整数；解冻与工单规则仍按已确认 ND。下文各 ND 的「当前问题」列保留历史提问原文，**不得当作现行合同**。
- `RESOLVED_WITH_GATE` 表示原则已确认，但仍需要技术、真实小样或上线门禁证据；不等于功能已经实现。
- `PARTIAL_OPEN`、`CONFLICT_OPEN` 和 `SCOPE_EXCLUDED_RISK` 项仍不得进入未经门禁的真实写入、收费或外部调用；`BOUNDARY` 项只能按临时边界执行。
