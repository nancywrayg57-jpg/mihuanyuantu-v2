## 4. 失败归因（≥3 条可执行线索）

1. **UnivFD 对本集即梦/豆包几乎无检出能力**（66 张仅 1 张豆包被检出）→ 不能用作「处理后变实拍」的证明；符合风险 R1。  
2. **nonescape / hybrid 对微信导出与实拍误报极高** → 与「平台二次压缩/导出」分布相关；若继续开源路线，需针对微信导出子集校准或换训练域。  
3. **hybrid 对处理后图几乎全杀（B≈95–99%）** → 物理化/频域扰动反而增强其「假」信号，或后端 HF 头过敏；不宜作为通过率优化目标。  
4. **nonescape 三轮 B 递减（52→37→35）** → 多轮处理有弱化「AI 痕迹」趋势，但仍远未到 &lt;5%；可作处理强度调参的参考信号，不能过门禁。  
5. **CommunityForensics HF 打包损坏** → 后续若坚持该路线，须改用论文官方权重/正确二分类头，而非当前 `LABEL_0` 单维包。
