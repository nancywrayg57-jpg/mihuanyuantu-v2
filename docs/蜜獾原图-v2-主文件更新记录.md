## 2. 初版 → 现版：必须知道的差别

初版以归档 **PRD v1.0（1.27）** 与 **架构 1.0** 为准；现版以 **PRD 2.10** 与 **架构 1.7** 为准。

| 主题 | 初版 | 现版 |
|---|---|---|
| 主流程 | 文生图/图生图生成后**自动**进入五层与最终检测；上传/导入也走同一条「生成历史」链 | 四种来源先入**图片资源**；生图成功只入库；**批量原图**另选图提交处理 |
| 计费 | 每条图片任务链最多 10 积分（生成+五层捆价） | **每张成功 10 积分**；生图入库与处理通过**可先后各收**；自动轮次不叠加 |
| 冻结 | 提交时冻结（含生图） | **生图不预冻**，成功入库后扣；**处理提交前**按张数×10 冻结 |
| 导航 | 生成历史统一四类来源；可有独立检测页（1.27 已移除） | **任务详情**双标签（默认处理，其次生图）；按账号隔离 |
| 复制 | 生图任务可复制参数且免再次冻结（ND-025） | **仅处理任务**可复制免冻；生图不提供复制 |
| 下载 | 允许 ZIP 批量包 | **禁止 ZIP**（RP-009）；勾选后目录写入，否则逐文件下载 |
| GPS | 客户可选地点 / 转经纬度 | **只随设备预设**（none / fixed / random_by_scene）（RP-010） |
| 账号 | 强调租户隔离 | **一租户多账号**：积分租户共用；资源/任务/消息按账号隔离 |
| 检测 | Gemini Vision 已是正式检测（FR-018） | 2026-11-02 **再次确认生产**；Check/Synthbuster 不写入合同（RP-011） |
| 自动重做 | 适用于四类来源整链；链级最多 10 | 只作用于**图片处理任务**；该张最多消费一次 10 |
| 数据库 | 架构初稿含 RDS 询价 | **本地自建 PostgreSQL**；首期不采购云库 |
| 对象存储 | 架构 1.3 写阿里云 OSS 私有桶 | **架构 1.7 / 物料：LocalDisk 默认**；OSS 适配器预留（2026-11-04 grill；1.7 消歧 §8.3） |
| 积分归属措辞 | 「无共享钱包产品化」易误解 | **租户共用积分户**；无席位订阅（PRD 2.8） |
| 实现阶段 | §13 把几乎全产品捆成「第一版本 MVP」 | **首期**单张规则替身闭环；真实五层/真 Gemini/生图/客户业务 API 等后置 |
| 客户 API | 第一版不开放程序调用 API（ND-017 / RP-002 旧口径） | **2.10 / 架构 1.7**：开放本平台业务 API（`X-API-Key` + 能力名 `image_processing` 映射路径 + OpenAPI/Swagger，FR-033 / AC-024）；复用 `api_keys`；仍禁上游模型 Key 自助与外部代发；不进首期退出（R3/S5）；§7 含订单客服 A |
| 未改 | 五层保真与字节下限、Gemini ≥75 且 `passed=true`、自动重做阈值/次数、整数积分、五档充值、aojuai 底座、经济起步、失败有效结果可下载不收费 | 同左 |
