## 3. 可复用材料与使用边界

- `01_源码参考/原样快照/`：21 个文件，包含 11 个模块 / 字典 / 适配文件及 10 个相关测试文件，按旧相对路径原样保存；另有 5 个 Schema、路由、查询及导入模板片段。原样快照内的旧注释、旧规则和缺陷一并保留，仅作为来源证据。
- `02_设备参数/`：405 条完整候选、原分类 / 建议形态分类、48 个不同机型的 93 条双来源规格记录、67 个 Schema 字段、58 列导入模板及 4 条示例、66 条 EXIF tag 赋值和 65 组界面选项。仅有名称或局部规格的设备不补造缺失字段。
- `03_复用评估/`：说明直接参考、改造后迁移及仅作反例的边界。五层顺序、原尺寸、sRGB JPEG、最终字节下限和付费调用失败规则以 v2 需求为准。
- `04_提取与校验/`：保存离线提取脚本、来源 SHA-256、文件指纹和校验结果；脚本不连接生产、数据库或模型，不执行旧源码。

全部 405 条线上记录的 `is_public` 值均为 0，已保留 PRIVATE 来源标记，未携带旧用户归属。提取并不将这些记录发布为系统公共模板。候选分为 233 条结构候选和 172 条需复核记录；两类均完整保存，结构检查通过不证明摄影数值真实或图片效果合格。
