# 设备参数分类与复用说明

## 1. 本次取得什么

线上 405 条预设全部保留，来源 ID 不重复。原分类为 phone=125、dslr=119、mirrorless=101、action=60。每条候选含原参数、来源 ID、旧分类、来源可见性、建议设备形态、需复核标记、运行时覆盖项和 NOT_RUN 验证状态。

“完整”指对这次可见数据范围的提取完整及设备字段保留完整，不表示原预设的摄影参数正确。线上原始响应有 117 个不同键，包含别名与运行元数据；保留其中 58 个规范设备 / 来源键，账号、IP、固定坐标、署名、使用统计与日期值未保存，别名通过字段映射保留定义。线上扩展字段 `ai_img2img_strength` 已补入，不能因为本地 Schema 未声明就丢弃。

全部来源记录 `is_public=0`。本包保留 PRIVATE 来源事实，不保存 user_id，也没有替新系统决定归属和公开权限。候选不能自动作为系统内置公共库导入。

## 2. 四个旧分类与更多设备形态

分类字典四项是旧软件的存储 / 筛选口径。设备名称还包括 Pocket、360 / MAX / X4、GFX、X100VI / Q3、M11 / M11-P 等系列，因此本包额外提供按名称规则划分的 9 组检索视图，计数和路径见 [总入口](../README.md)。

这些建议规则都写为 `ADVISORY_NAME_RULE_NOT_VENDOR_VERIFIED`。手机标签优先保留，避免把 vivo X100 Pro 因“X100”子串误归入 Fujifilm X100；Insta360 品牌名本身也不等于每款都是全景相机。未知类别与未知型号不因四类白名单被丢弃。

仅对大小写、空白和重复的品牌前缀做显示名归一化，**未把 ILCE 产品码与 A7 名称、SM 产品码与 Galaxy 名称等未经核验的别名自动合并**。完整来源目录的 192 条是检索条目，不是去重后真实设备数量。

## 3. 三种数据层级分开使用

| 层级 | 数量 | 能做什么 | 不能推定什么 |
|---|---:|---|---|
| 线上预设 | 405 | 逐条迁移摄影参数、场景与提示词作为候选；保留原 ID 追溯 | 不能仅凭旧“健康度 / EXIF 评分”认定真实、合规或能通过新检测 |
| 源码机型规格 | 93 条记录，48 个不同机型 | 提供传感器尺寸、参考像素尺寸、FocalPlane 数值的来源参考 | 不具备 ISO / 快门 / 光圈 / 镜头等完整预设，不代表厂商规格已核验 |
| 界面选项 / MakerNote 名称 | 65 组选项 | 发现品牌、设备、镜头、场景与可选值；补充名称目录 | 不因菜单里出现就补造参数或认定支持 MakerNote |

ExifTool writer 有 48 个机型，旧 piexif writer 有 45 个；共有机型参数一致，差异是 Apple iPhone 16、16 Pro、16 Pro Max 三个机型只存在于前者。不是同机型的两份已确认数值冲突。

FocalPlane 参考表没有逐项声明分辨率单位。本包仅以本地 Schema 默认单位 3（厘米）作**条件一致性检查**，计算 `pixelWidth / (sensorWidth_mm / 10)` 和对应纵向值；偏差大于 5% 标记需复核。这个假设和阈值不构成对设备真实规格的裁决，也未自动重写任何值。

## 4. 逐条复核结果

- 233 条 `STRUCTURAL_CANDIDATE`：通过本轮必需字段、正数、快门格式与 ISO 范围等有限结构检查；仍需摄影语义、厂商规格和图片 / EXIF 往返验收。
- 172 条 `QUARANTINE_REVIEW`：仍完整保存，不丢弃。96 条 phone 记录的“实际焦距”超过 30mm，76 条 dslr 记录的机型名称触发分类复核规则。两项是保守的筛查提示，不能单靠阈值认定设备无效。
- `15s`、`30s` 等 10 条带单位的长曝光值保留原串，另提供去单位的归一化建议；没有将有效长曝光当作非法快门，也未用归一化建议覆盖原参数。
- 405 条均为 `NOT_ACTIVATED`，所有厂商规格核验、图片处理和 EXIF 往返验证均为 `NOT_RUN`。不设置“已批准可投产”模板数量。

## 5. 字段差异与必须覆盖的旧值

本地 parameters 表实际提取 **67 个字段**；导入模板实际 **58 列**，尽管源码注释写“62列”。模板缺少 AI 提示词 / 强度和 FocalPlane 等字段，却包含 Schema 中没有的 `lighting`、`background`、`post_processing`、`prompt_template`。不能只导出 CSV / Excel 就声称已保存完整设备参数。

已识别的类型 / 语义差异包括：

| 字段 | 旧材料中的差异 | v2 处理原则 |
|---|---|---|
| ambient_light | Schema 为整数 lux，模板示例为 Natural Light 等文字 | 保留来源，分别定义光照数值和场景字典，不强制转 0 |
| sharpening / noise_reduction | Schema 为整数，模板为 Normal / Low 等文本 | 明确新类型与字典映射；不能静默强转 |
| image_orientation | Schema 为 landscape / portrait，模板是 1 / 3 / 6 / 8 | 区分构图方向与 EXIF 方向，最终以像素方向归一化和回读为准 |
| compression_ratio | Schema 是整数，模板为 0.85 等小数 | 只保留参考；最终采用新 JPEG 编码配置与字节下限 |
| maker_note_template | 名称既有机型全文又有 apple_iphone15pro 等代码 | 建立显式版本化映射；名称不等于真实可写 MakerNote |
| ai_strength / ai_img2img_strength | 本地字段与线上扩展字段并存 | 保留差异供追溯，不启用旧第 0 层图生图 |
| image_width / image_height | 旧机型和示例具有多种原生像素尺寸 | 可作设备参考，不能用于缩放 v2 图片或伪填最终尺寸 |
| image_format / color_space / color_depth | 旧示例包括 HEIC、Display P3、14bit JPEG 等混用 | 最终统一按 v2 的 sRGB JPEG 实际编码值，不继承不一致声明 |
| GPS / ip_geo | 旧运行记录有固定坐标、IP 或随机场景区域 | 值不迁移；按当前任务地理与隐私策略重新解析 |
| author / copyright / user_id / is_public | 旧署名、归属和私有状态 | 不继承旧身份；来源状态保留，启用时单独配置新归属 |

四条源码导入样例保留在单独文件，标为 `EXAMPLE_ONLY_NOT_PRODUCTION_PRESET`；例如 Canon EOS R5 示例的旧 dslr 标签、14bit JPEG 声明等问题不能混入正式模板。源代码注释声称“真实参数”不等于本轮已验真。

## 6. 迁移时的最小批准证据

每个启用版本至少明确：设备唯一键和别名、建议分类的人工核对、真实规格来源、ISO / 光圈 / 快门 / 焦距及单位、镜头与传感器一致性、输出事实覆盖、真实 EXIF 写入回读、MakerNote 支持等级、版权 / 归属以及固定图片小样结果。

本包不补造缺失参数。字段不足的机型继续作为部分规格或名称候选保存；核验通过后另建新模板版本，保留本次原始快照。图片 / EXIF / 端到端尚未验证。[未经本地验证]
