# 发布/回滚 Runbook 模板

## 1) 发布前

- [ ] 迁移脚本已审阅
- [ ] 配置项清单已确认（不要提交敏感信息）
- [ ] 冒烟用例清单已准备

## 2) 发布步骤（无 Docker）

1. 拉取代码
2. 执行迁移：`alembic upgrade head`
3. 执行 seed（如有）
4. 重启后端与前端
   - 端口建议：后端 `38000`、前端 `38848`
5. 冒烟验证：`/health` + 登录 + 菜单 + 核心列表

## 3) 发布后（闭环）

- [ ] 关键链路通过
- [ ] 检查日志（error/info）无异常峰值
- [ ] 记录问题与结论，更新文档/skills

## 4) 回滚策略（最小）

- 代码回滚：
- 迁移回滚（如允许）：
- 数据修复：
